VATTool 19 - How to use
=======================

1. In Odoo, export the Journal Items for ONE month as a CSV file.
   Do not open or save this file in Excel.
2. Open VATTool 19 and click "Browse..." to pick the file.
3. Fill in Submitter person and Submitter EGN (the tool remembers them).
4. Click "Run". When it is done, click "Yes" to open the results.

Where are my files?
  Documents\vattool_19\<company VAT>\<month>_run001
  Every run makes a new folder (run001, run002, ...). Old runs are kept.
  The .txt files are for NAP. The .csv files are for checking in Excel.

"Warnings: YES"
  Open run_summary.txt and read the list at the bottom:
  - "SKIPPED": this document is NOT in any file. Tell Tony.
  - a name change, like 'Légiközlekedési' -> 'Legikozlekedesi':
    NAP cannot read accented letters, so the tool removed the accent
    in the .txt files. Nothing to do.
  - "truncated": the text was too long and was cut. Usually fine.

Something went wrong?
  - "Config error": click "Yes" to restore the settings.
  - Any other red error: send Tony a screenshot and the CSV file.

Please do not
  - run the tool from Program Files,
  - change the files in the "configs" folder unless Tony asks you to.
